| No secrets in the deployed assets                 | PASS           | `apps/web/scripts/check-deploy.mjs` (runs in `pnpm run deploy`) refuses `.dev.vars`/`.env` files and anything shaped like an OpenRouter key in `dist/client`.                                                                                                                                                                                                                                                                                                                                                     |

| CORS / origin                                     | PASS           | Non-GET requests with a foreign `Origin` are rejected; no `Access-Control-Allow-Origin` is sent.                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Session cookie                                    | PASS           | `HttpOnly`, `Secure`, `SameSite=Strict`, HMAC-signed, 2 hours.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Turnstile in production                           | PASS (guarded) | The repo still has Cloudflare's test site key for local work; the deploy check refuses to deploy with a test key.                                                                                                                                                                                                                                                                                                                                                                                                 |
| CLI approvals cover every write/exec tool         | PASS           | `ToolRegistry` asks `ctx.approve` for every tool whose kind isn't `read` (one central check, `tools/registry.ts`), including mode tools (`run_python`, `export_csv`). Git refuses default branches and force pushes in code.                                                                                                                                                                                                                                                                                      |

## Cost (measured 2026-11-11, default model `anthropic/claude-haiku-5.5` at $0.10 / $0.50 per million input/output tokens)

One real message per mode, measured as the change in the OpenRouter key's usage:

| Mode (message)                              | Tool calls | Cost    |
| ------------------------------------------- | ---------- | ------- |
| General: define a word                      | 0          | $0.0003 |
| Study Buddy: short summary of a 3-page PDF  | 1          | $0.0004 |
| Dev Tools: explain a small repo             | 0          | $0.0008 |
| Data Analyst: one question on a 729-row CSV | 1          | $0.0012 |
| Dev Tools: dependency upgrade plan          | 0          | $0.0012 |
| Dev Tools: API test cases for 2 groups      | 5          | $0.0018 |

- **Typical:** about $0.001 per message, so $6 covers roughly **5,000 messages**.
- **Worst case per request** (60k chars of history, 6 steps, full output): about $0.02. One free message can trigger up to 10 tool follow-ups, so a determined user could spend about **$0.25 per free message, $2.50 per IP per day**. Many IPs could drain the credit, hence the caps below.
- Total spent while building phases 1–9: **$0.13**.

**Recommendations**

- Keep `FREE_DAILY_LIMIT` at **10**.
- Use a **separate production OpenRouter key with a credit limit of $3** (half the balance). That's the hard cap: when it's reached, the free tier stops and BYOK keeps working. If OpenRouter offers a reset period for key limits, use **$0.50 per day** instead.
- Watch usage daily in the first week (see LAUNCH.md). If spend passes $0.50 in a day, lower `FREE_DAILY_LIMIT` to 5 or flip the kill switch.
- Not built (would need code): a global daily message cap across all IPs. Worth adding if traffic grows.
