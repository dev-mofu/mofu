# Roadmap

Ideas noted during the build. None of these are built yet.

**Safety and cost**

- A global daily cap on free messages across all IPs (today the hard cap is the OpenRouter key's credit limit).
- A contact `mailto` in Crossref requests to join their "polite pool".
- Cache arXiv and Wikipedia responses briefly in the Worker to stay well under their rate limits.

**Features**

- OCR for scanned PDFs in Study Buddy.
- APIForge: run tests from the browser against CORS-enabled APIs, GraphQL support.
- Data Analyst: SQLite and Parquet files; more data sources.
- Dev Tools on the web: private repositories with a GitHub token kept in the browser.
- Sync memory and flashcard progress across devices (would need accounts).

**Polish**

- Self-hosted fonts to avoid the font swap on first visit.
- A smaller Python download on first use.
- Translations of the landing page and docs.
