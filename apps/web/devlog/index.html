Dev log

Every Mofu update, newest first. The full history is in the commit log.

Nov 12, 2026

mofu fix, mofu commit, mofu pr, and builder checks in the browser and MCP

mofu fix --run "npm test" reproduces a failure, explains the root cause, and after you agree fixes it on a branch and reruns the command. mofu commit and mofu pr write the commit message and the pull request for you to approve. The app's Dev Tools can now audit a contract and find secrets right in your browser, and the MCP server has scan_secrets and audit_solidity.

Read the docs →

Nov 12, 2026

For builders: secret scanning, contract checks, AI review, GitHub Action

mofu secrets finds wallet keys, seed phrases and API tokens in your files and your whole git history. mofu audit reads a Solidity contract before you deploy and says what Mofu's Token Scanner will flag, plus common bugs. mofu review reviews a branch or pull request with AI and can post the comments. And a GitHub Action runs the secret, contract and dependency checks on every PR.

Read the docs →

Nov 12, 2026

Smarter token checks: code fingerprints, sell depth, mofu-sdk

Token scans now fingerprint the contract's code and flag tokens built from the same code as known honeypots, whatever they're called. When a sell works, Mofu also measures how big one sale can be before the price drops 10%. And mofu-sdk wraps the API for agent builders, with a tunable buy rule and webhook signature checks.

Read the docs →

Nov 12, 2026

For agents: CLI checks, a public API, webhooks and an agent template

npx mofu-cli scan and npx mofu-cli wallet run the Token Scanner and Wallet Health in the terminal, with --json for scripts and --fail-on to stop a pipeline. The same checks are a JSON API at /api/v1. Webhooks watch tokens and send a signed POST when the owner, supply, code, pause state, liquidity or verdict changes. And a trading agent template on GitHub asks Mofu before every buy and refuses what Mofu flags.

Read the docs →

Nov 12, 2026

Safety kit: approvals, sell test, deployer history, copycats

Paste a wallet to see every active token approval, who the spender is and which are risky, then revoke them in one click. Token scans now simulate a buy and a sell (taxes and the ETH that comes back), list the creator's other launches as active or quiet, and flag tokens that copy another one's name or ticker. Known contracts are named, token pages get an embeddable "Scanned by Mofu" badge, and the MCP server has check_wallet.
