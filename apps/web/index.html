One agent, real tools

Mofu doesn't guess numbers. It calculates, looks things up and checks its work.

Data Analyst

Drop a CSV, Excel or JSON file. Mofu profiles it, answers questions by running Python (pandas) in your browser, draws charts and can pull in exchange rates, holidays, weather or World Bank data.

Study Buddy

Upload a PDF or notes, or paste an article. Get summaries at three levels, flashcards you can export to Anki and quizzes that grade themselves, with page citations.

Dev Tools

Explain any public GitHub repository, scan dependencies against OSV for known vulnerabilities, and turn an OpenAPI spec into test cases, docs and a breaking-change report.

In your terminal

npx mofu-cli works on the folder you're in: coding tasks on a branch with your tests, dependency upgrades, API test runs. It asks before changing a file or running a command.

How it works

  1. Drop a file

    A spreadsheet, a PDF, a manifest, a spec, or just a question.

  2. Mofu works with real tools

    Python, public data sources, vulnerability databases and your own tests.

  3. Get a usable result

    Answers with sources, charts, flashcards, test files or a pull-request-ready branch.

Private where it counts

  • Your files are read in your browser. Spreadsheets, PDFs, manifests and specs are opened on your device. Only what's needed to answer, like a data profile, the pages being read or a list of package names, is sent to the AI model.
  • Python runs on your device, in a sandbox with no network access.
  • No account. A quick bot check, then you're in. Settings, memory and your own key are kept in your browser's storage.
  • We don't store your chats. Messages pass through Mofu's server to the model provider via OpenRouter, whose own policies apply. The server only keeps a daily message count per IP address, which it deletes after the day resets.
  • Your own key stays in your browser and is sent with each request only to call the model. Mofu's server never logs or stores it.
  • In the terminal, everything runs on your machine, and Mofu asks before changing files, running commands or touching git.

FAQ

Is it free?

Yes. The web app gives you 10 free messages a day, with no account. For more, add your own OpenRouter key in Settings. The CLI always uses your own key.

What are the limits?

Free: 10 messages a day per IP address, PDFs up to 30 pages at a time and data files up to 20 MB. With your own key there's no daily cap and PDFs can be up to 300 pages. The CLI handles bigger files.

Which models?

By default, Claude Haiku through OpenRouter: fast, cheap and good with tools. With your own key you can pick any OpenRouter model that supports tool calling.

Can I bring my own key?

Yes, an OpenRouter key. It's kept in your browser and only used to call the model; you pay OpenRouter directly for what you use.

What data do you store?

On our side, only a daily message count per IP address for the free tier. Your chats, files and key aren't stored by Mofu's server. In your browser, Mofu keeps your settings, what you asked it to remember and your flashcard progress.

Which file types?

CSV, TSV, Excel (.xlsx) and JSON for data; PDF, .txt and .md for studying; package.json, package-lock.json, requirements.txt and pyproject.toml for dependency scans; OpenAPI 3 or Swagger 2 specs in JSON or YAML. Scanned PDFs (images of text) aren't supported yet.
