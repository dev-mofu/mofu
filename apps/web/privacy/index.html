Privacy policy

What happens to your data when you use Mofu.

The short version

  • No account. We don't ask for your name or email.
  • Files you open in the web app are read in your browser and aren't uploaded to Mofu's server.
  • Your messages, and the parts of your files needed to answer, are sent to an AI model through OpenRouter.
  • Mofu's server doesn't store your messages, files or API key. It keeps a daily message count per IP address for the free tier.

What is sent where (web app)

To Mofu's server, then to OpenRouter and the model provider

  • your messages and the conversation so far;
  • facts you asked Mofu to remember;
  • context Mofu needs to answer, built in your browser: for example a profile of your spreadsheet (column names, types, summary statistics), the results of Python run on it, an outline and the pages of a document it reads, a GitHub repository overview, the list of packages in a dependency scan, or an API spec's endpoint list;
  • your own OpenRouter key, if you added one, so the request is billed to you.

Mofu's server runs on Cloudflare Workers. OpenRouter passes the request to the model provider (by default Anthropic). Their own privacy policies and terms apply: openrouter.ai/privacy.

Directly from your browser to other services

Depending on what you do, your browser contacts GitHub (to read a public repository), OSV and deps.dev (vulnerability and package data), public data APIs (exchange rates, holidays, weather, World Bank), Wikipedia and dictionary services, Crossref, Open Library, Datamuse, and jsDelivr (to download the Python runtime). They see your IP address and the request (for example a package name or a search term), as with any website.

Bot check

Cloudflare Turnstile runs before your first message. Cloudflare's privacy policy applies.

What is stored, and where

Where What How long
Mofu's server A count of free messages per IP address per day Deleted about an hour after the daily reset (midnight UTC)
Mofu's server A signed session cookie (no personal data) 2 hours
Your browser (cookie) If you connect a wallet for $MOFU holder perks: a signed cookie holding your wallet address 7 days, or until you choose Disconnect
Mofu's server If you connect a wallet: a count of messages per wallet address per day, used instead of the IP count Deleted about an hour after the daily reset (midnight UTC)
Mofu's server logs The type of an error when something fails (no message content, no keys) Cloudflare's standard log retention
Your browser Settings (theme, model), your own key if you add one, what you asked Mofu to remember, flashcard progress Until you remove it (Settings → Remove key, Memory → Clear all, or clear site data)
Your computer (CLI) ~/.mofu/config.json (your key, if saved with mofu auth), ~/.mofu/memory.md, ~/.mofu/study/ (flashcard progress), ~/.mofu/pyodide-cache/, and reports in ./mofu-output/ Until you delete them

Mofu's server doesn't store chats or files and doesn't use your data to train models. Whether a model provider keeps data is governed by OpenRouter's and the provider's policies.

Your IP address

The free tier counts messages per IP address to keep the service affordable. The IP address is used as the key of that counter and is deleted with it.

Wallets and $MOFU holder perks

Connecting a wallet is optional. Your wallet signs a plain text message to show the address is yours; it's not a transaction, costs no gas and gives no access to your funds. Mofu then reads that address's public $MOFU balance on Robinhood Chain through a public RPC node, which sees the address but not who you are. Mofu doesn't store balances beyond a minute of caching, and never asks for approvals or your seed phrase.

A wallet address is public on the blockchain, so connecting links your use of Mofu to that address for as long as the cookie and the daily count exist. Disconnect removes the cookie.

If you vote in the holder roadmap vote, Mofu stores your wallet address with the option you chose for as long as that vote runs. Results show totals only: how many wallets and how much $MOFU backed each option, never who voted for what.

The Token Scanner sends the contract address you paste to Mofu's server, which reads that contract through public Robinhood Chain RPC nodes. Mofu keeps a count of scans per IP address (or per connected wallet) for the day, and caches a scan result for two minutes.

Wallet Health sends the wallet address you paste (or the one your wallet connects) to Mofu's server, which reads its token approvals and balances from GoldRush and the chain. Mofu doesn't store the address or the results beyond a few seconds of caching; each check counts as a scan for the day's limit. The names and tickers of tokens it sees are remembered, without the wallet, to spot lookalike tokens later. A revoke is sent by your wallet straight to Robinhood Chain; it doesn't pass through Mofu.

The public API (/api/v1) and mofu scan / mofu wallet in the CLI work the same way, and count toward a daily allowance per IP address that's deleted after the day resets. If you create a webhook, Mofu stores its URL, the token addresses it watches, its signing secret and delivery counts, so it can check those tokens and send events. It's kept until you delete the webhook, or deleted a week after it's switched off for failing. Your IP address isn't stored with it.

When a scanned contract is a token, its address, name, symbol and result are added to the public list at mofu.works/token and get their own page. The list never shows who scanned a token or when you did. Token pages are cached for about half an hour, and each uncached page view counts toward a daily limit per IP address.

Through the MCP server (mofu.works/mcp), your AI app sends Mofu the contract address or the manifest files you ask it to check. Mofu uses them to answer that one call (manifests go on to OSV and deps.dev as package names and versions) and doesn't store them. A count of tool calls per IP address is kept for the day.

The public counters on mofu.works/stats (messages, scans, transactions explained, Mofu Guard checks and stops, MCP calls, wallets connected, votes) are plain totals. They don't record who did what, from where, or about which address.

The CLI

The CLI runs on your computer. It sends your messages, and the file contents it reads to answer, to OpenRouter using your own key. When it fetches a web page or API spec you give it, or runs API tests, it contacts those addresses from your computer.

Children

Mofu isn't directed at children under 13.
